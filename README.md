# Практична робота: вбудовані колекції Python

Демонстраційна програма охоплює списки, кортежі, словники, множини та вимірювання продуктивності. Вхідні дані для перших чотирьох завдань відтворювані. Зовнішні пакети не потрібні: використовуються лише модулі стандартної бібліотеки Python.

## Запуск

Потрібен Python 3.10 або новіший.

```text
python main.py
```

Запуск послідовно виконує п'ять завдань, виводить підписані результати та перезаписує `benchmark_results.csv` результатами поточного вимірювання. Скрипт очікує `sample_text.txt` у тій самій теці; файл читається в кодуванні UTF-8.

## Файли

- `main.py` — реалізації п'яти завдань.
- `sample_text.txt` — фіксований текст для словника частот.
- `benchmark_results.csv` — медіани, мінімум і максимум часу на одну операцію в секундах, кількість циклів на повтор і число повторів.
- `requirements.txt` — зовнішніх залежностей немає; скрипт використовує стандартну бібліотеку.
- `README.md` — інструкція запуску та короткий опис.
- `report.pdf` — оформлений звіт із результатами одного запуску.

## Що демонструється

1. Індексація, зрізи, копіювання та мутації списку на місці.
2. Кортежі-записи, розпакування, агрегування вартості та мутабельний список усередині кортежу.
3. Підрахунок нормалізованих Unicode-слів словником, безпечний `.get`, сортування та похідний словник через dict comprehension.
4. Унікальність, перетин, об'єднання, симетрична різниця, перевірка підмножини та `frozenset` як ключ.
5. Порівняння перевірки належності у list/set/dict та побудови унікальних значень через список і множину.

## Метод вимірювання

Для кожного розміру `n = 100, 1 000, 10 000` використано `timeit.repeat` із п'ятьма повторами. Пошук перевіряє останній елемент списку, щоб продемонструвати лінійний прохід. Для побудови унікальної структури вхід містить повтори (`i // 2`). Ініціалізація тестових даних відбувається поза вимірюваною операцією. У таблиці наведено медіану та межі `[мінімум; максимум]` часу на один виклик. Числа залежать від комп'ютера й фонових процесів; повторний запуск оновлює CSV.

Очікувані складності: пошук у списку — `O(n)`; належність у множині та словнику — у середньому `O(1)`; побудова унікального списку з перевіркою кожного елемента через `in` — до `O(n²)`; додавання елементів до множини за один прохід — у середньому `O(n)`.
